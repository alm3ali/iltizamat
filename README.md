# التزاماتي

مخطِّط شخصي للالتزامات الشهرية والدورية: الفواتير، الأقساط، المصاريف السنوية، الطوارئ، والديون.
يجيب عن سؤال واحد: **كم أحوّل لحساب الالتزامات كل شهر حتى لا يفاجئني شيء خلال 12 شهراً؟**

- بلا خادم وبلا مكتبات. البيانات في IndexedDB على الجهاز فقط، ولا تغادره.
- المواصفات: [`SPEC.md`](SPEC.md) — التقدم: [`PROGRESS.md`](PROGRESS.md)

## التشغيل
```sh
npm test          # اختبارات وحدة المنطق
npm run serve     # ثم افتح http://localhost:8080
```
